🏗️ Platform Architecture · v1.6

Four integrated components.
One solved problem.

HomeGuarantee is a B2B2C platform with four layers: a financial guarantee product, a matching platform, an administrative experience layer, and a supply-expansion program for distressed properties. Each layer unlocks a different segment of landlords previously unable or unwilling to house formerly homeless individuals.

Component 1

The Guarantee Product

A financial guarantee of up to $20,000 per tenancy, covering every meaningful risk a landlord faces when housing a formerly homeless individual.

✓
Property damage exceeding the security deposit — covered up to $20K
✓
Unpaid rent up to 3 months — guaranteed
✓
Vacancy loss during post-tenancy repair — up to 30 days
✓
Court and legal filing fees if eviction proceeds — covered
✓
Claims paid within 30 days via ACH — no bureaucratic delays
📊
Oregon benchmark: OHCS program data shows avg claim ~$3,500, claims rate ~12%. At HomeGuarantee's $87.50/unit/month fee, the math closes at 300+ active units.

Component 3 · Phase 2.5

HomeGuarantee Managed + Works

The Managed tier is a full-service property management offering that abstracts all post-placement landlord responsibility. Staffed by HomeGuarantee Works employees — formerly homeless individuals hired into living-wage roles.

Managed tier features ($175–225/unit/mo)

🔧 Maintenance request intake → vetted trades network → landlord summary only
📋 Quarterly property condition reports with photo checklist and health score
🏘️ HOA complaint handling under TX Property Code §202.004 and fair housing law
🤝 Neighborhood Ambassador visits — pre-move-in and 90-day follow-up
✉️ Monthly plain-English landlord summary — no action required
🏅 "Certified HomeGuarantee Property" badge — reframes social narrative

The Works circular economy

HomeGuarantee Works employs formerly homeless individuals in property-related roles — creating a circular system where housing placements generate employment, and employment enables more placements.

Works base wage$16.83/hr ($35K/year)
Works roles at 500 managed units~12 direct hires

♻️
The Works program is funded by Managed tier revenue — not grants. By Year 3, it is self-sustaining and provides the renovation labor for the Stabilization tier.

Release Plan

Phased delivery: manual-first, then scale

Months 1–6

Phase 1 — Manual Pilot

50 units. No tech required. Validate the guarantee product and claims model before building software. Manual matching, PDF guarantee agreements, staff-reviewed claims.

Success criteria: 50 units, 5 claims processed, ≤12% claims rate, landlord NPS ≥40
Months 7–12

Phase 2 — SaaS Platform

200 units. Build the minimum platform: landlord portal, case manager dashboard, HMIS integration, automated rent payment, claims management.

Success criteria: 200 units, 21-day time-to-keys, HMIS API live, platform covers ops costs at 300+ units
Months 9–18

Phase 2.5 — Managed + Works

Launch Managed tier at $175–225/unit/month. Hire first 12 Works employees. Establish trades network. HOA-community and absentee landlord segments unlocked.

Prerequisite: Texas PM licensing determination + landlord WTP validation
Months 13–17

Phase 2.5b — Supply Expansion Discovery

Resolve 5 kill switches (K6–K10). Run HCAD property scan. Contact 50 distressed owners. Scope renovation depth per owner segment. Validate SSI payment default rates.

Kill switches must pass: Chapter 10 equivalence, SSI default rate, owner reachability, Works-SSI interaction, Solar PPA availability
Months 18–22

Phase 2.5b — Stabilization Launch

First 10 renovation-for-commitment agreements → 10 renovations → 10 active Stabilization placements. Validate labor ceiling calculations on 5 real properties. Confirm Works-SSI non-overlap design.

Target: 50 distressed units converted by Month 24
Month 13+

Phase 3 — Scale

500+ units. Insurance partnership (reinsurance above $5K). Multi-HA support (HCHA + others). Landlord referral program. National expansion pilot (Chicago, Denver, Phoenix).

Target: 2,000 active units by Year 2; 6,000 by Year 3
